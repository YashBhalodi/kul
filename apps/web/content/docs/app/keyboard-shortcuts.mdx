---
title: Keyboard shortcuts
description: Every keyboard shortcut in the Kul app, by where it works.
---

On a Mac, <kbd>Ctrl</kbd> in this list means <kbd>⌘</kbd>, and

<kbd>Alt</kbd> means <kbd>⌥</kbd>. The one exception is
<kbd>Ctrl</kbd>+<kbd>Space</kbd>, which is the Control key everywhere.

In the app, press <kbd>?</kbd> to see this list.

## Anywhere

| Shortcut                     | What it does             |
| ---------------------------- | ------------------------ |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open the command palette |
| <kbd>?</kbd>                 | Show keyboard shortcuts  |
| <kbd>Ctrl</kbd>+<kbd>J</kbd> | Show or hide the editor  |

## Files

| Shortcut                     | What it does             |
| ---------------------------- | ------------------------ |
| <kbd>F2</kbd>                | Rename the selected file |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the file’s tab     |

Browsers keep <kbd>Ctrl</kbd>+<kbd>W</kbd> for closing the browser tab in
most cases. Use the × on the file's tab, or middle-click it, instead.

## In the editor

These work while the editor has the keyboard. There, <kbd>F2</kbd> renames
the id under the cursor rather than the file.

| Shortcut                                      | What it does                   |
| --------------------------------------------- | ------------------------------ |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd>              | Suggest completions            |
| <kbd>F12</kbd>                                | Go to the declaration          |
| <kbd>Shift</kbd>+<kbd>F12</kbd>               | Find every use                 |
| <kbd>F2</kbd>                                 | Rename a person or marriage id |
| <kbd>Ctrl</kbd>+<kbd>.</kbd>                  | Show quick fixes               |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>  | Format the file                |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Go to a person or marriage     |
| <kbd>Ctrl</kbd>+<kbd>/</kbd>                  | Comment or uncomment lines     |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>                  | Undo                           |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo                           |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd>                  | Redo                           |
| <kbd>Ctrl</kbd>+<kbd>F</kbd>                  | Find and replace               |

## On the canvas

These work while the canvas has the keyboard: click the tree's background
first.

| Shortcut       | What it does               |
| -------------- | -------------------------- |
| <kbd>0</kbd>   | Fit the tree to the canvas |
| <kbd>+</kbd>   | Zoom in                    |
| <kbd>-</kbd>   | Zoom out                   |
| <kbd>←</kbd>   | Pan left                   |
| <kbd>→</kbd>   | Pan right                  |
| <kbd>↑</kbd>   | Pan up                     |
| <kbd>↓</kbd>   | Pan down                   |
| <kbd>Esc</kbd> | Clear the selection        |
